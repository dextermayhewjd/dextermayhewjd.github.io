两侧使用同一条 **Harness 调用 → Sandbox 能力 → E2B 后端 → 返回调用者** 主线。左侧保留采用前的完整讲解；右侧阅读稿已采用到正式页，与正式页使用同一份正文。

| 对比位置 | 原有讲解 | 已采用稿 |
| --- | --- | --- |
| 阅读入口 | 生命周期位置在前，再看调用与返回图 | 直接显示当前 Sandbox 职责的局部图 |
| 当前语境 | 从 run 的用户准备进入环境能力 | 保留同一入口，明确接收什么、留下什么、回到哪里 |
| 源码展开 | 六步读法，再下钻接口、后端与文件能力 | 沿一次具体环境操作连起代码、对象和产物 |
| 文件能力与生命周期 | 配置写入后补充文件、创建与收尾 | 区分本章共用能力、正常返回与外层管理 |
| 源码定位 | 文件与行号在正文中直接显示 | 解释旁默认折叠，独立保存核对清单 |

并排时两侧可独立滚动；也可用“新标签打开”比较完整页面宽度。
