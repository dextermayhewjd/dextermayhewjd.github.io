## 1. 每次只学一个新问题

全课分成 **8 个模块、41 个编号单元**，最终包含已选定的 **82 项 API/方法**，以及理解它们必需的语法和异常类型。第 10、11 单元各有两个独立子课；17–41 的编号保持不变。

**01–20 已整理完成，21–41 是后续拆分与补写的规划。** 当前顺序先学任务状态、取消与整组失败，再学按完成顺序取结果、超时、时间预算和取消传播，目前已进入协程之间的协调。旧 URL 保留，不能用网址数字推断新课号。

本专题只讲 Python 原生异步与并发。每个单元只增加当前必要的关系；源码与完整位置清单放在各页末尾按需展开。

### 现在从哪里继续

已经理解 Lock 的互斥保护，可以从 [20 · asyncio.Event：让任务等待一个通知](../20-async-event/) 继续。沿 wait、set 与 clear 区分等待、唤醒和真正执行，并理解一个标志怎样通知多份任务。

需要复习时，返回 [09 · Task.cancel](../09-task-cancellation/)、[11.1 · TaskGroup 的失败与收尾](../11-taskgroup-failures/) 或 [17 · asyncio.Semaphore](../06-semaphore/)。

每次按这个顺序学习：

1. 确认本单元列出的前置已经理解。
2. 只解决本单元的问题，预测并运行主例子。
3. 能复述原子结论并完成自查，再进入下一单元。
4. 模块结束时回看等待、结果和退出是否能串起来；全课结束时再做只含已学机制的综合自查。

## 完成全课时检查什么

1. **82 项调用/方法都有正式讲解。** 仅在代码里出现、作为辅助展示或放进源码清单，不算完成解释。
2. **相关语法和异常没有遗漏。** 包括 `async with`、`async for`、异步生成器、`try/finally`、`except*`，以及取消、未完成读取、队列空满和子进程超时。
3. **能解释边界。** 分清安排与执行、任务与结果、协程挂起与线程阻塞、取消请求与真正退出。
4. **能观察失败和清理。** 不只会运行正常路径，还能指出异常、取消与超时之后谁负责等待和释放。

课程规划已做逐项映射检查；当前正文完成状态仍以上方说明为准，不把规划覆盖当作已经掌握。
