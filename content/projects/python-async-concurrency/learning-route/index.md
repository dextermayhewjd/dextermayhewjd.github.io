## 1. 每次只学一个新问题

全课分成 **8 个模块、40 个最小学习单元**，最终包含已选定的 **82 项 API/方法**，以及理解它们必需的语法和异常类型。一个单元可以介绍同一对象的几个配套方法，不要求把 82 个名字当作 82 课逐个背。

**01–05 沿用现有课程，06–40 是后续拆分与补写的规划。** 下方链接指向可复用的旧课材料，旧页面的编号和 URL 暂时保留；课程有规划入口不等于正文已经完成。

本专题只讲 Python 原生异步与并发。每个单元先带上前文结论，再说明一个新增要求，最后用最小例子验证。框架源码、全部位置清单和可选细节仍按需展开。

### 现在从哪里继续

前五课已经沿着“创建协程 → 内部等待 → 安排任务 → 分组等待 → 收集结果”建立基础。**下一步只看第 06 单元：gather 等整组，怎样先取得已经完成的任务？**

先使用[现有第 06 页的 wait 部分](../04-results/#wait-results)，只理解 `done/pending`；Task 的结果读取安排在第 07 单元，`as_completed` 安排在第 08 单元。

每次按这个顺序学习：

1. 确认本单元列出的前置已经理解。
2. 只解决本单元的问题，预测并运行主例子。
3. 能复述原子结论并完成自查，再进入下一单元。
4. 模块结束时回看等待、结果和退出是否能串起来；全课结束时再做只含已学机制的综合自查。

## 完成全课时检查什么

1. **82 项调用/方法都有正式讲解。** 仅在代码里出现、作为辅助展示或放进源码清单，不算完成解释。
2. **相关语法和异常没有遗漏。** 包括 `async with`、`async for`、异步生成器、`try/finally`、`except*`，以及取消、未完成读取、队列空满和子进程超时。
3. **能解释边界。** 分清安排与执行、任务与结果、协程挂起与线程阻塞、取消请求与真正退出。
4. **能观察失败和清理。** 不只会运行正常路径，还能指出异常、取消与超时之后谁负责等待和释放。
