怎样连接接口和组合对象。下面每页都有 Python 主例子和两种写法对照。

| 模式 | 解决的问题 |
| --- | --- |
| [适配器 · Adapter](adapter/) | 把现有接口转换为调用方期待的接口。 |
| [桥接 · Bridge](bridge/) | 让两个变化维度可以独立组合。 |
| [组合 · Composite](composite/) | 用一致的方式处理单个元素和嵌套容器。 |
| [装饰器 · Decorator](decorator/) | 在现有行为外面逐层添加功能。 |
| [外观 · Facade](facade/) | 为一组子系统提供一个方便的调用入口。 |
| [享元 · Flyweight](flyweight/) | 让大量对象共享可复用的状态。 |
| [代理 · Proxy](proxy/) | 在访问真实对象时加入控制。 |
