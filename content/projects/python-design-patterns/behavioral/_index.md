怎样分配行为和协调协作。下面每页都有 Python 主例子和两种写法对照。

| 模式 | 解决的问题 |
| --- | --- |
| [责任链 · Chain of Responsibility](chain-of-responsibility/) | 让请求依次经过多个可选择处理的环节。 |
| [命令 · Command](command/) | 把一次操作保存成以后可以执行的值。 |
| [迭代器 · Iterator](iterator/) | 逐个产生元素，让调用方不必了解内部结构。 |
| [中介者 · Mediator](mediator/) | 把多个参与者之间的协作集中到一个中间角色。 |
| [备忘录 · Memento](memento/) | 保存状态快照，以便以后恢复。 |
| [观察者 · Observer](observer/) | 一次状态变化，通知多个订阅者。 |
| [状态 · State](state/) | 让同一个对象在不同状态下响应不同。 |
| [策略 · Strategy](strategy/) | 保持调用流程不变，替换其中的算法。 |
| [模板方法 · Template Method](template-method/) | 固定处理步骤，把可变化的步骤留给调用方。 |
| [访问者 · Visitor](visitor/) | 针对一组对象类型增加新的操作。 |
