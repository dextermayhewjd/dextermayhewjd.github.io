用户指出：

此前助手把 `_translate` 的局部结构示范标作 Step 0，项目旧入口又指向外层启动与训练，未能展示用户所要的 Coding Agent 起点。

## 助手本轮核对的材料

助手曾提前静态核对 `generate` 的准备、Harness 调用、diff 收集、独立评估、结果返回与 Session 清理，以及 `BaseHarness.run` 和 Adapter 的交互。这些提前准备不能证明用户已选择该轮主题；对应的本步讲解、函数卡片和核对文件已按后续要求删除。

这些是助手提供的定位与解释；当前没有用户对整条新模型的职责复述，没有运行 Agent、模型服务或评估环境。
