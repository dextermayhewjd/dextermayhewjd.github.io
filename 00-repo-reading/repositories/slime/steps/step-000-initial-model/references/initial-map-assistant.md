## 最小整体模型：解释草案

```text
任务数据与配置
  → 组织生成：模型或 Agent 执行任务，并取得评分
  → 整理可供训练消费的样本 / 数据引用
  → 训练侧消费，更新参数
  → 把新权重交回生成侧，继续后续轮次
```

这是一轮工作的职责轮廓。它还不解释如何启动服务、怎样执行工具、怎样并发或恢复。评测也可能单独执行；不能理解成每次模型请求、每份任务都立即对应一次训练更新。

围绕岗位，先看清任务、模型、工具、上下文、评分和训练数据的交接，再按具体问题展开并发、Trace、恢复与资源。训练内部和集群内部先保留明确接口，需要时再深入。这个取舍不改变框架实际包含的职责。
