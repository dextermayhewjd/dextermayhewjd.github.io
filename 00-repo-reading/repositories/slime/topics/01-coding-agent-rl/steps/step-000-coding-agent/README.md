## 每一轮先确认什么

先一起讨论“这一步准备读哪个函数、围绕它要弄清什么、短期 memory 准备保留什么”。助手可以提出候选函数及理由，由用户确认本步范围和记录重点，再展开源码和建立相应记录。这里不要求提前给出答案或证明已经掌握。已有明确指定就直接沿用，不重复询问。

仅同意阅读方向、看过旧材料或助手准备好了内容，不等于确认了本步函数与记录重点。确认前可以讨论候选，但不提前展开函数讲解、创建该函数的记忆或写入已开始的进度。
