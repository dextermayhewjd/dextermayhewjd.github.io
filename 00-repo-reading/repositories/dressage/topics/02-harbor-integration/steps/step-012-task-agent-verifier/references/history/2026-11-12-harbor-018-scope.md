### 3.2 本步骨架与阅读顺序

先追配置怎样组成一次尝试，再返回 Trial 中查看这些配置何时被消费。下图按职责交接展示，未把配置读取和 Agent 执行误写成同时发生。

```python
Job._init_trial_configs
  -> TaskConfig + AgentConfig + attempt 配置
  -> TrialConfig                         # 交给 Trial 生命周期使用。

Trial._prepare
  -> 准备任务要求的 Environment
  -> BaseInstalledAgent.setup(...)
       -> self.install(environment)      # 由所选 Agent 实现。
            -> ClaudeCode.install(...)   # 本轮代表路径。

SingleStepTrial._run
  -> Agent.run(...)                      # 使用任务 instruction。
  -> Verifier.verify(...)                # 运行题目约定的验证并读取奖励。
  <- Agent 结果与验证结果                 # 留在 Trial 结果中。
```
