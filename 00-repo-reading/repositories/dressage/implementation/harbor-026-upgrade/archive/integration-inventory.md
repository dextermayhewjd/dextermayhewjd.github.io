## 3. 怎么判定已覆盖

1. **先回答“哪些地方可能受影响”。** 固定两份提交，复算所有 Python 的直接导入、包级版本读取、后端同名实现、CLI/配置文件命中。把回调、`Any` 上的字段、动态配置和文件协议顺着真实调用方追到消费者。逐处原行放在附录，人在主表一次只审一行。[源码附录](../usage/harbor-call-sites.md)
2. **每行都要能回答“哪种结果算匹配”。** 有返回值就检查下游实际读取的字段、类型、身份或数值。返回 `None` 的接口就看它承诺的副作用。相同输入先过 0.18.0，再过 0.26.0；数值或行为变化时，在对应 issue 给出两份原文和取舍理由。[12 的实测对照](../investigations/12-reward-validity/README.md#evidence)
