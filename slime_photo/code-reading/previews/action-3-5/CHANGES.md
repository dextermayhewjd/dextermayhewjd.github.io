# 3.5 候选稿的变化

候选：[完整阅读稿](reading.md)；证据：[源码校验](SOURCE-CHECK.md)。正式页和原材料保持原样。

| 层次 | 原材料 | 候选稿 |
| --- | --- | --- |
| 页面入口 | 正式页只有图与外链 | 在独立候选页直接展示完整讲解，不替换正式页 |
| 主线定位 | 调用骨架在末尾 | 局部图后先接上 _run_turn 的真实调用 |
| 输入理解 | 分散列出若干字段的用途 | 先用表格说明生成记录、历史、工具、请求和会话标识的交接与最小理解，再看当前输出的短示例 |
| 每步实现 | 示例输出较完整，代码集中在末尾 | 保留全部 JSON 示例，就近补短代码和默认收起的源码出处 |
| 对象关系 | Reply 提供两种表示，turn 更新 | 明确 Reply 的不同消费者、完整参数与实际读取成员，以及 replace 新建记录 |
| 响应边界 | 区分非流式与流式 | 保留区别，进一步说明构造对象不证明网络送达；补断连与取消的轨迹/清理分支 |
| 阅读收口 | 返回响应与接回 Launch Agent | 增加复述题；下一目录为 Pre-4 回看准备，避免把阅读顺序当执行顺序 |

图和 JSON 示例未改动。原材料与本地阅读快照的四个相关源码文件完全相同；本轮使用隔离替身验证了解析、响应和轨迹行为，没有运行模型、真实 tokenizer 解码或网络服务。详细结果见 validation.json。
