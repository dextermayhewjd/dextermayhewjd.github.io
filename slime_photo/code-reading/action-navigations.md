# 4.1 各章的简短阅读导航

用户已要求将 Action 6 试用的形式统一到各个当前章节：阅读问题之后、首图之前放一个短的缩进伪代码块。已读步骤与前后调用简写，当前职责用注释标出；详细实现仍在图后的原有讲解里。

[action-navigations.json](action-navigations.json) 保存八个章节的文件、导航哈希和已授权文件变更。它与 [action-contexts.json](action-contexts.json) 共用固定源码快照；后者提供入口、文件与符号证据。

导航是阅读定位，不能复制执行。`generate()` 编排一次任务；2／3／3.5 通过运行中的 CLI 发出的 HTTP 请求进入 Adapter；5 的能力贯穿多处调用；6 等待 CLI 结束，7 展开运行期间的模型回连。每章突出自己的职责，不能照搬同一条顺序流程。

原稿源码是否保留的校验排除 `reading-navigation` 块。历史候选、原 README 与图保持原有角色；Action 6、7 当前只在原讲解上增加导航，没有采用 Action 6 候选中的整套改写。

每章代码块内的省略项都带 Action 编号和职责范围。任务准备、启动组织、长命令执行、HTTP 回连、单轮模型处理与任务收尾分别标注；Action 5 单独说明覆盖准备、运行和回收的环境能力。该规则应用到各章阅读伪代码本身，而非仅用于目录或总览说明。
