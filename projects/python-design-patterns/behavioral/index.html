模式解决的问题

模板方法 · Template Method

总览 / 行为型 1. 要解决什么问题 固定处理步骤，把可变化的步骤留给调用方。 当多个类实现相同的整体算法流程（例如数据导入流水线：打开文件 -> 提取原始数据 -> 解析数据 -> 输出报告 -> 关闭文件），但各个子类在某些特定步骤的处理细节上有所不同。如果让每个子类各自实现完整流程，会导致算法骨架和通用步骤代码大量重复。 ...
