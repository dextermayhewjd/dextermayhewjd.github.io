执行一条命令

Agent 想运行测试，最底下需要什么能力？

修改文件、读取文件、执行命令，是代码 Agent 做事需要的三种能力。slime 用 Sandbox 把这些能力放在一个小接口里。
exec() 返回退出码、标准输出和错误输出。上层只调用这个接口；E2BSandbox 再把调用交给 E2B 服务。以后换执行环境时，可以沿用上层代码。
Agent 要求：运行 python -m pytest
Sandbox.exec：执行命令
返回：(0, "3 passed", "")

这是一次成功执行的示意。非零退出码与命令输出也是结果的一部分。

slime/agent/sandbox.py · E2BSandbox.exec

            return res.exit_code, res.stdout or "", res.stderr or ""

要换成另一家沙箱，为什么不用先改 Agent 启动逻辑？

展开复述参考因为启动逻辑依赖 Sandbox 的执行和文件接口；新后端实现这些能力即可。镜像创建等提供方细节留在后端。
更多细节与源码出处

E2BSandbox 在进入 async with 时创建环境，退出时尝试销毁；镜像和生命周期配置由环境变量或构造参数给出。

远程调用可能重试。_rpc_retry 只有在错误被判断为暂时故障且操作可重放时才重试，防止把有副作用的命令执行两次。
