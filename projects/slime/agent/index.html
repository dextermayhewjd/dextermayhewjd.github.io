Agent 基础小课

一、先让 Agent 做事

从一条命令到一个可替换的 Agent CLI。

  1. 执行一条命令 未学
  2. 等一条长命令结束 未学
  3. 把启动步骤固定下来 未学
  4. 让 Codex 使用指定模型入口 未学
  5. 换成 Claude Code 启动器 未学

二、把回答留下来

从输出文本到可训练的多轮轨迹。

  1. 识别回答中的工具调用 未学
  2. 保存一次真实采样 未学
  3. 分清哪些 token 参与训练 未学
  4. 处理分支和上下文改写 未学

三、接上模型服务

让 Agent 使用 slime 正在训练的模型。

  1. 把一轮请求送到模型 未学
  2. 为一次任务收好尾 未学
  3. 让 OpenAI 格式接入同一条链 未学
  4. 把 Anthropic 内容块翻译进来 未学
  5. 让 Adapter 持续接收请求 未学

四、拼成完整任务

准备任务、独立评分，再返回 slime。

  1. 把组件拼成一个代码任务 未学
  2. 让测试决定任务结果 未学
  3. 把自己的 Agent 接回 slime 未学
