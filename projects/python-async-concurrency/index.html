Python 异步与并发

逐步理解 Python 原生异步、线程、进程与同步机制的运行、等待和退出。

先学清楚一份任务怎么完成#

先看完整 01–41 课 API 与语法出现次数：按首次引入的课程逐项排列，列出全部 98 项接口及配套语法在 verl、AReaL、Slime、Miles 中的统计；同课只显示一次课号，待编写课程另作标注。

这份专题只讲 Python 原生异步与并发。目标是说明工作何时开始、谁在等待、多少份可以同时推进，以及失败或退出时怎样清理。Slime、AReaL、verl 的真实用法帮助选择学习重点，框架业务与通用工程化不在本专题展开。

从第 1 节开始即可。 只需知道 Python 函数、参数、返回值和变量赋值；不要求先理解强化学习、Ray 或模型服务。先用一句话认清本节概念，再沿小实验观察它的行为。Slime 对照与源码位置放在每页末尾，按需展开。

最初六个单元逐步增加知识点：01 创建协程对象，用 run 执行 → 02 在协程内部用 await 等待 → 03 用 create_task 安排任务 → 04 读懂 with / async with 的进入和退出 → 05 用 TaskGroup 等待组内任务 → 06 用 gather 收集结果。 前一节的最小结论，成为后一节的起点。

开始：async def 定义之后，什么时候执行？

想先了解整体范围，可看学习路线与完成标准：按任务结果、退出、负载、线程、上下文和进程逐步展开，并区分必学与按需内容。

忘了前面学过什么，或不确定几个 API 的关系时，打开知识地图与回忆练习：从问题找概念，先回忆、再核对，用短代码检查理解，并留下自己的错因。

01–16：先建立任务执行的主线#

节本节解决的问题
01 · async def：定义之后，什么时候执行？先分清异步函数、协程对象和真正执行的函数体。
02 · await：等待结果，不等于自动并发沿执行顺序理解挂起、恢复和 asyncio.sleep。
03 · create_task：先安排工作，再等待结果对比直接 await 与提前创建 Task，分清安排任务和等待结果。
04 · TaskGroup：离开代码块前，等任务结束沿用两份任务，只增加退出组时等待全部任务结束的关系。
05 · gather：等待一组任务，收集一组结果等待已创建的 Task，按传入顺序收集返回值。
06 · wait：先取得任务的完成情况区分 done/pending，用已学的 await 取值并等完剩余任务。
07 · 取消与超时：请求停止以后，还要等待收尾理解 cancel、CancelledError、finally 和任务级超时。
08 · Semaphore：限制同时进入的工作数量把并发许可与任务总量区分开。
09 · Queue：把生产速度和消费速度接起来用有界队列理解等待、背压与结束信号。
10 · 线程池：把阻塞工作移出事件循环理解 to_thread、run_in_executor 与两类 Future 的边界。
11 · Lock、Event 与线程退出线程共享状态怎样保护，后台线程怎样收到停止信号。
12 · async with、async for 与异步生成器把异步资源的进入、迭代和退出连起来。
13 · ContextVar：让并发任务保留各自的上下文区分任务上下文与共享全局变量，并恢复进入前的状态。
