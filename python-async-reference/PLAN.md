# Python 官方异步文档与三仓库使用统计

目标：收齐用户指定的 12 个 Python 3.16 官方页面、asyncio 官方目录的其他页面，以及直接相关的语言/标准库文档；据此建立 Slime、AReaL、verl 的可追溯静态使用统计。

## 范围与边界

1. 使用本地三个 Git 仓库当前已跟踪 Python 文件，固定 HEAD、逐文件哈希和工作区差异；不修改源仓库，不运行模型或训练。
2. 统计静态位置，不称作运行次数。导入、调用、非调用引用、异步语法和实例方法候选分开。
3. 文档保存官方 URL、抓取时间、实际版本标题、HTML/纯文本副本、页面 API 目录；用户列出的页面必须逐一核对。
4. 用户补充确认：范围只限 Asyncio 与并发处理。补充范围为协程/异步生成器/上下文协议语言参考，以及线程、执行器、并发 I/O、进程、上下文和异步测试。普通反射、数值运算、文件操作等不统计；较大标准库页面仅选择其中的相关条目。
5. 目录与统计不等于学习掌握程度；缺乏类型证据的对象方法不算成已确认的标准库调用。

## 文件与接口

1. `tools/collect_docs.py`：收集官方文档；产生 `official/catalog.json`。
   - 页面字段：`id`, `url`, `title`, `category`, `status`, `html_path`, `text_path`, `sha256`, `fetched_at`, `symbols`, `links`。
   - 符号字段：`name`, `url`, `kind`, `signature`。
2. `tools/scan_repositories.py`：扫描三个本地仓库，产生 `repositories/<repo>/inventory.json`、元数据及相关源码快照。
   - 保留既有扫描器的事件字段、类型证据和静态分析边界；新增规范化 API 名与证据强度，不覆盖已有 Slime 教程统计。
3. `tools/build_reports.py`：将文档符号和源码记录连接，产生文档目录、跨仓库统计表、逐页明细和待核实清单。
4. `README.md`：总入口、完整范围、使用说明、复跑命令和主要结果。
5. `tests/`：文档抽取、分类/计数及链接映射的行为检查；整体校验文档和源码文件哈希、已确认 API 引用及报告一致性。
