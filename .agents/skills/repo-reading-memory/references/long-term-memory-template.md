# 长期记忆：函数模板

用于本步 `03-long-term-memory/functions/<源码相对路径>/<完整函数名>.md`。从上一步的 `03 + 02` 合并完整条目，保留原话、场景、输入输出、模型、未知和来源；只补充继承来源并核对链接。当前函数版式见[短期模板](short-term-memory-template.md)与 [BaseAdapter._translate 样例](base-adapter-translate.md)。旧快照保持原有版式，不因继承强制重排。

```markdown
# <完整函数名>

- 源码定位：<保留原文件、符号、版本和行号>。
- 首次接触：<保留原步骤>。
- 最近认识更新：<保留实际理解更新步骤>。
- 继承自：<上一步及完整来源记录链接>。

<以下原样保留前序记录正文；合并新认识时保留前后变化及各自来源。>
```

没有前序模型时，只在 overview 写“暂无继承”。只继承或改排版不更新“最近认识更新”，不扩写个人理解；本步新认识先写入本步短期记忆。继承来源与原始形成过程是两条不同的线索，移动后分别核对目标。
