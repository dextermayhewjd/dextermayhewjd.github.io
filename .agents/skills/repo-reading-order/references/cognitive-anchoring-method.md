# 认知心理学阅读法：情节锚定与契约脚手架（Anchoring & Scaffolding）

记录日期：2026-10-22。

## 1. 认知问题定义：为什么脱离情境读抽象接口会造成认知过载？

认知负荷理论（Cognitive Load Theory）表明：
- **执行器编排（如 `generate`）**：在大脑中建立的是**情节记忆（时间链/动词序列）**，回答“一件事怎么发生、怎么收场”；
- **接口契约（如 `Protocol` / `ABC`）**：在大脑中建立的是**语义记忆（空间图/名词边界）**，回答“谁负责什么、边界在哪里”。

若先读抽象接口，大脑缺乏具体的运行时上下文，必须花费宝贵的工作记忆去“虚拟脑补”调用场景，导致外在认知负荷激增；
若先读执行器流程，大脑先建立**情节锚点（Anchor）**，产生“这个方法背后到底怎么实现的”的自然悬念，此时再看接口契约，心智模型即刻闭环。

## 2. 适用规则（推荐阅读顺序时的判断依据）

面对包含“高层执行编排（Executor/Orchestrator）”与“底层抽象接口（Contract/Protocol）”的代码库时：
1. **第一优先级（锚定）**：先剪枝提取执行编排函数的正常主线（10–20 行核心动词）；
2. **第二优先级（解惑）**：带着执行编排中的调用点，下钻阅读对应的接口与协议定义；
3. **第三优先级（实现）**：最后看接口的具体实现类（如具体沙箱后端、驱动细节）。

此方法与 [向心跳跃法](inside-out-method.md) 互为支撑，适用于 Slime、Dressage 及同类 Agentic RL 框架。
