# Python 异步知识地图与回忆练习

用户已确认：在现有课程之外提供问题导向的知识树、带含义的关联、先回忆再核对的卡片、短代码判断与个人复习记录。保留课程顺序，编写完成与掌握程度分开。

## 边界与实现

- 第一版覆盖已整理的 01–21 单元，以约 20 张概念卡组织六类问题；22–41 只链接到后续课程规划。
- 课程编号、标题和链接从 `curriculum.json` 解析，不复制维护另一套课程表。
- 知识卡与有向关系保存在 `python-async-reference/knowledge-map.json`；每张卡有回忆问题、解释、易错点和可运行的小题。
- 用户主动标记“需要提示 / 能独立解释 / 能判断代码”。点击、浏览、展开答案不改变熟悉程度。建议间隔为 1 / 3 / 7 天，可提前复习，不宣称是个性化最优间隔。
- 记录仅存当前浏览器，含回答、错因、最近练习与复习时间；提供 JSON 导出和校验后导入，合并时保留较新的记录。
- 桌面分栏，窄屏上下排列；不设置嵌套滚动区。使用语义化按钮、折叠和表单，反馈可由读屏读取。

## 执行与验证

1. 先添加状态、数据约束测试，确认新功能缺失时失败。
2. 实现数据、纯状态模型、Hugo 页面、交互与导航入口。
3. 执行每份 Python 小题，对照预期输出；验证复习不会由浏览动作触发。
4. 浏览器检查桌面、窄屏、键盘、保存恢复和导入导出；运行现有课程与导航检查。

不改课程归属、不自动判定已掌握、不引入账号或服务器保存，不提交或发布网站。
