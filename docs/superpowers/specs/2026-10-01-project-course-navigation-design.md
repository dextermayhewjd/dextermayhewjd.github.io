# 项目与课程方向导航设计

## 目标

把个人网站从“文章列表”扩展成“知识方向入口”：访客先进入一个项目、课程或领域，再沿着该方向的总览、章节和具体笔记逐层阅读。

## 设计

使用 Hugo 原生 section 层级表达方向和章节。每个方向有一个 `_index.md` 作为总览页，下面的 Markdown 文件按文件名排序形成章节导航。方向页面和方向内文章共用一个左侧导航，当前页面高亮；移动端将导航折叠为可展开区域。

第一版提供 `content/courses/mit-1806/` 作为真实样例，包含课程总览和三篇章节笔记。项目和其他课程可以沿用相同目录结构，不需要额外注册 JavaScript 数据或手工维护全站导航。

## 边界

- 保留现有 PaperMod 顶部菜单、文章目录和感悟抽屉。
- 方向导航只显示当前方向的内容，不把全站文章混在一起。
- 目录只依赖 Hugo 页面树与 front matter，排序由 `weight` 控制。
- 第一版不增加搜索、进度同步或用户账号功能。

## 验收标准

- `/courses/` 能展示课程方向入口。
- `/courses/mit-1806/` 能展示课程总览和章节列表。
- `/courses/mit-1806/01-systems/` 等章节页有当前课程的左侧导航，并高亮当前页。
- 普通文章和 `/notes/` 继续按原有方式渲染。
- `hugo --gc --minify` 构建成功。
