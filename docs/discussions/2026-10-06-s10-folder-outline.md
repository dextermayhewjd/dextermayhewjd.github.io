# S10 的文件夹式章节目录

用户认为模块较多、层次不清晰，并明确要求简单的 `1`、`1.1` 列表，像文件夹目录。

把正文组织为四个主层次：定位；任务记录与依赖；认领与完成；接回 Agent Loop 与实现边界。每层保留具体小节，正文标题和开头目录使用一致编号。新增简短“实际工作”小节，区分查看、认领与执行；原有代码、三图、依赖示例和解释保留。

目录通过 `chapter-outline` shortcode 直接使用 Hugo 的标题目录，避免维护两份名称。使用缩进与细分支线表达归属，不另画系统流程图。S10 关闭主题的重复目录，仅在正文开头显示该树状目录。稳定的 `task-store`、`task-tools`、`task-dependencies`、`task-claim`、`task-complete` 锚点移到对应 H3 标题，原局部阅读器链接继续有效。

验收检查目录包含四个主目录、十五个子目录，逐项名称与 H2/H3 一致，点击可跳转；检查源码摘录、图与函数联动、页面 ID 唯一及窄屏不溢出。

已验证：Hugo 构建和导航检查通过；S10 在 390、1180、1600 宽度下的目录跳转与原图文交互、源码一致性检查共四项通过。人工截图确认两级目录采用列表与分支线，现有本地预览已更新。

后续补充：2.1 内新增 2.1.1–2.1.5 局部目录和函数说明，每段代码前写清作用、输入输出与文件副作用，区分 save/load/list 三个 TaskStore 方法和 load_task/list_tasks 两个顶层包装。全章目录仍保留两级，细分留在 2.1。构建、导航、源码摘录一致性与五个局部锚点检查通过，本地预览已更新。
