# 把图形拆解保存为可选的阅读笔记格式

## 问题与决定

用户希望把 Learn Claude Code 的图 1／图 2 学习方式留下来，作为后续阅读或开发笔记的模板之一。

提取已经确认的规则，不重新设计颜色或网站交互。采用两种模式：演化对照回顾真实旧系统，再展示本轮系统；独立机制先定位宿主，再展开内部过程。复杂演化才增加图 3，初始章节不强行构造上一轮。

这种区分避免把“当前关注的机制”与“历史上新增的机制”混为一谈，也不要求每篇笔记永久使用三图。

## 落盘与复用

- [通用方法](../diagram-reading-method.md)：图组、颜色、折叠边界、代码对应与发布前自检。
- [草稿模板](../../archetypes/mechanism-note.md)：问题与来源、图 1／图 2、可选图 3、分段代码、主流程、例子与验证。
- README 与原写作规则增加入口；原章节细则继续保存在原文档。

草稿通过 `hugo new content --kind mechanism-note projects/my-project/01-mechanism/index.md` 生成。使用叶子页面包，方便后续读取同目录 SVG 资源。默认 draft，不自动生成图、启用交互或把旧章节改成新格式。
