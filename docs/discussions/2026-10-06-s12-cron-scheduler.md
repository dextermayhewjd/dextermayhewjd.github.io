# S12 Cron Scheduler：从到期规则到 prompt 交付

延续分层目录、三图对照、输入输出悬停、内部函数点击就近阅读。源码基准是本地 ce8f9f186058939da54c9d6fead78dfb5d0fd6c3。

规则保存 cron、prompt、recurring、durable、pending_delivery 与 last_fired。计时线程每秒检查本地时间，新的匹配先保存待交付状态再入队。队列处理线程等 agent_lock 空闲，使用共享 session_history 启动一轮；用户主线程也可在回合入口消费队列。

Agent Loop 入口取走队列并追加 Scheduled user 消息，首个模型响应成功后才 ACK，周期规则清 pending、一次性规则删除。失败删除本次追加的消息并恢复队列。接收确认不等于工作成功，确认写盘失败或重启可能导致重复交付。
