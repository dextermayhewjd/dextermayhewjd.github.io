# Lecture 14：奖励学习与序列策略

用户要求在 Lecture 10 后按相同方式处理 Lecture 14，并发布到 GitHub。新增页保留 22 个公式编号和主要拆解，将奖励来源、语言模型概率、优势、参考正则和历史状态接成可点击流程。

图中 30 个节点，四个完整算法组：回答训练六步、奖励—策略交替五步、RLHF 外循环四步、PPO-for-LLM 八步。奖励来源从同一问题分成 IRL 与偏好/验证器，汇入策略训练；GAE 与组内相对权重是两种优势来源；完整交互历史包含过去动作。

数学核对：

- 指数奖励先作为似然因子，配分积分求导后先认出归一化密度，再写回期望。
- 将动力学因子与实际策略轨迹概率分清，两侧在同一基测度上同时消去动力学。
- 自归一化 IS 有有限样本比值偏差；随机动力学下完整最优性后验不必由因果策略精确实现。
- 不将 IRL、GAN、GAIL 和 AIRL 的所有目标都划成同一个公式；奖励迁移需结构假设。
- 完整 completion 比值是 token 比值连乘；token PPO 是局部代理。
- 组均值含自身有相应缩放，随机标准差和裁剪另有影响。
- KL 比较完整分布；本批旧策略和长期参考不同，采样 log 比的均值才是 KL。
- 部分可观测环境不能仅靠观测窗口自动恢复充分状态；价值可定义，单观测 Bellman 递归才是关键障碍。
