# 点击节点追踪输入、输出与引用

用户希望点击节点后看清使用与引用的箭头，以理解输入输出。

后续澄清：主要需要的是悬停预览。现改为鼠标进入节点即高亮输入、输出与引用，移开恢复先前固定选择或默认总览；悬停不会打开详情或改变已点击的模块。触屏滚动不触发预览，点击功能继续保留。

范围：S08、S09 的图 2 总览。本章模块仍打开原有详情，其他节点只显示关系；第一张回顾图保持静态。章节链接保留导航行为。

每条边使用 `data-from`、`data-to`、`data-kind`、`data-label` 标明真实语义。选中节点后，高亮与它直接相连的边与箭头，淡化无关边；在图旁列出输入／前序、输出／去向、引用关系及条件。既覆盖普通工具回路，也覆盖 Skills 引用、压缩条件分支与 Memory 读写。

不新增表示输入输出的配色。蓝、橙、紫仍用于章节演化；选中用加粗、淡化和文字说明。选中箭头头部固定为 12px，保持线的原色，避免随粗线无限放大。Stop 反馈和超长补救返回边标明汇入主循环，避免把接点误读为另一节点。

每次仅追踪一个节点，再次点击、Esc 或恢复默认取消。支持键盘 Enter／Space，关系说明可由辅助技术读出。图的节点位置、连线路由、字号与详情中的函数联动保持稳定。

为避免详情挡住路径，面板增加“只看连线”：收起详情并保留当前追踪，再次点击模块可打开详情。

验证关注：输入及条件输出均被高亮；SYSTEM 引用可独立选中；召回包含磁盘来源与 SYSTEM 去向；切换与取消无残留；演化颜色和回顾图不受影响；桌面、宽屏和手机可以操作。

已检查两张图的实际高亮截图：S08 SYSTEM 的引用、S09 召回的两条输入及 SYSTEM 输出均能分辨。路由、端点有效性、构建及导航检查通过；浏览器覆盖 390、1180、1600 宽度的选择、键盘、恢复默认和只看连线模式，以及 S08 无增强回退。
