# S08：固定教学视图与局部交互试点

## 问题与本轮范围

用户希望系统性处理总图随章节成长而变得臃肿的问题。单纯扩大 SVG 画布无法减少要同时追踪的关系；自由展开全图又会使跨章比较的基础不稳定。

本轮只在 S08 落地已经讨论的规则：固定默认总览，按需查看单个模块的详情。保留 repo 的压缩机制、逐段代码与三张主图，不推广到其他章节。

## 已采用的设计

- 图 1 继续复用 S07.9 的节点、几何与连线。灰色虚线提示 Skills 内部与权限／日志回调的合并，读者选择不改变回顾图。
- 图 2 默认显示预处理、普通摘要、主动 compact、异常补救，以及原循环中的入口与返回位置。内部节点从 25 个减少到 20 个，画布高度从 870 减至 660；显示宽度仍以 760 为基准。
- 旧回调归入执行前事件，Skills 保留目录与正文两个接口。转存、归档、缩短归入预处理摘要；模型调用成本、主动批次配对和一次重试限制保持可见。
- 七个 S08 模块使用相同的触发、输入、输出／状态、控制流、源码入口说明。这是本章覆盖范围，不是认知容量上限。
- 点击模块或下方按钮时，一次只打开一个局部详情。总图不重新布局；选择只加粗边框与关联线，不改变演化颜色。
- 详情复用正文中的图和代码，图内 ID 与引用在复制时独立命名。无增强脚本时仍可通过原生 details 和稳定锚点阅读。
- 图 3 与三个局部图保留在正文；在默认总览后加入四个自检问题及折叠答案。

统一规则已补入 [博客写作与架构图规则](../learn-claude-code-writing-rules.md)。

## 学习验证状态

**界面与结构已经验证；用户理解与学习效果尚未验证。** 不以节点减少、构建成功或点击测试通过推断学习收益。

试读时先不展开详情，依据默认图回答：

1. 压缩接在原循环的哪里？
2. 三个入口分别怎样触发？
3. 哪些步骤不调用模型，何时增加摘要请求？
4. 摘要或补救后怎样继续，什么时候停止？

再查看一个模块，检查能否找到其真实代码，并重新定位它在整体系统中的作用。用户反馈后再决定是否推广到 S09，或调整默认展开程度；本轮没有修改 S09 的架构。

## 试读反馈与位置修正

用户认可图本身，但指出点击后仍要向下移动页面才能理解预处理，阅读不连续。初版虽然通过行为测试，详情位置并不适合这项学习任务。

已根据反馈修正：

- 详情改为所点节点附近的浮动面板，在空间允许时放在旁边，否则紧接节点下方。原图不重新布局，打开不会滚动整页，长内容在面板里滚动。
- 面板保持在当前视窗内，不盖住所选节点，支持关闭按钮与 Esc。
- S08 的每张图保留实际色块的短图例，完整颜色与线型说明默认收起。回顾图“橙：将改造”与当前图“橙：改动”分别标注。
- 更新浏览器验收：检查面板与节点的距离、同屏范围、所选节点无遮挡、整页滚动量不变，以及完整图例能打开和收起。桌面、手机与无增强脚本三项通过。

用户对修正后的版本尚未给出新的试读结果，因此不把位置修正或测试通过直接记为学习效果提升。

## 可调整阅读尺寸

用户继续要求直接把详情区域拉大，并询问其 HCI 与教育价值。已加入右下角拖动、方向键微调、放大与恢复尺寸；尺寸始终限制在视窗内，总图位置和演化颜色不变。关闭后清除临时尺寸，切换模块时可以沿用本次打开的尺寸。

长内容改为面板内部独立滚动，标题、放大、恢复和关闭操作保持可见。放大后局部图可以利用更宽的区域，不把图压缩成更小的字。按钮操作为不便拖动的使用者提供替代方式。

浏览器检查覆盖拖动和方向键调整、放大、恢复、视窗边界与原图稳定。设计判断是：这已经是可用的个人学习试点，但放大后会遮挡更多总图，小屏局部图仍可能需要横向滚动。尚不能据此确认学习收益或把它定为所有章节的最终标准；仍需观察读者能否复述流程并应用到新情境。

## 步骤与函数连贯阅读

用户指出局部图中的每个步骤应与下方对应函数一起阅读，并希望有光标选中高亮。已把详情改成上图、下代码的阅读区，接口摘要可以单独展开；图与代码各自滚动，选函数时图继续可见。

`explorer.json` 逐节点记录实际函数。例如管线中的转存对应 `tool_result_budget`，归档对应 `snip_compact`，缩短结果对应 `micro_compact` 和 `fit_tool_results`；条件框关联 `estimate_chars` 与 `prepare`。输入、输出和文件状态节点只关联其实现，不另造函数。

函数代码复用正文的完整函数块。指针预览、点击固定与键盘选择都能高亮相应函数，点击后只滚动代码区；函数标题可以反向标出图中相关节点。高亮不改变架构演化颜色。

浏览器验收增加函数覆盖、条件框的真实实现映射、指针／键盘高亮、代码进入可见范围及整页不滚动。个人理解与学习效果仍待试读反馈。
